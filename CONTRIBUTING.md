# Contributing

This guide covers every cavi-ai repository that does not have its own CONTRIBUTING.md. A repository's own guide takes precedence.

## Issues

- Search existing issues before opening a new one.
- For a bug, include what you ran, what you expected, what happened, and your OS and product version.
- For a larger change, open an issue first so the approach is agreed before you write code.

## Pull requests

- Fork the repository and branch from `main`.
- Keep one change per pull request.
- Run the repository's tests and checks before opening it, and describe how you verified the change.
- Follow the repository's pull request template when it has one.

## Security and conduct

Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md). Everyone taking part follows the [Code of Conduct](CODE_OF_CONDUCT.md).
